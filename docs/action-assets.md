# 角色与动作素材

角色渲染统一在 src/cat-sprites.ts。现有行走图集继续使用；新增 cat-actions.png 为 4×4 透明动作表，依次为吃饭、蹲姿/刨砂、蹭蹭、蜷睡。生成后校准每帧脚底，运行时缓存为 64×64，统一地面锚点 (32,52)，以最近邻显示。

生成参考为项目既有 cat-atlas.png。动作图与 cabin-clean.png 使用 Image Gen 制作（2026-10-02）；原始背景与图集保留以便审查和回退。小屋清理图存在少量纹理变化，设施构图保持；不是声称逐像素无损编辑。

眼睛和粉色耳内保留，毛色重映射一次后缓存；装饰花单独绘制，不参与换色。首批复用一个猫形，不为每个品种生成独立动作表。

设施接触点按 960×640 世界坐标校准：食盆嘴部 (140/180,438)，猫砂盆 (806,432)，共享软垫中心 (745,470)，两只猫分别在左右 28px。猫砂盆前沿取自背景原区域；共同被子的纹理取自小屋软垫。

扩素材时先通过浅色/深色、昼夜、连续帧、设施遮挡检查，再增加花色。图集应无跨格、边缘残色或文字，切换姿态不能重新居中。
